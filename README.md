# A Return to Mathematics

A self-paced refresher for someone who has a math degree, has spent years writing software, and wants the ideas back. It starts from the language of proofs and climbs, field by field, through the undergraduate core, a first look at graduate material, and the questions people are working on now.

Each section is tagged **Core** (what a bachelor's degree covers, rebuilt from definitions), **Grad** (where a first-year graduate course takes it) or **Research** (open problems and recent results).

## Chapters

2. Logic, Sets and Infinity
3. Linear Algebra
4. Real Analysis and Measure
5. Complex Analysis
6. Abstract Algebra
7. Number Theory
8. Topology
9. Differential Geometry
10. Differential Equations and Dynamics
11. Fourier Analysis and Hilbert Space
12. Probability and Statistics
13. Combinatorics and Graph Theory
14. Algebraic Geometry
15. Computation, Logic and Categories
16. Numerical Analysis, Optimisation and Learning
17. The Frontier in 2026
18. Where to Go Next

## Reading it

It's a single self-contained HTML file (math rendered with KaTeX, fonts embedded). Either open `index.html` in a browser, or serve it, e.g. for a phone on the same network:

```bash
python3 -m http.server 8000
```

To publish it as a website, enable **GitHub Pages** (Settings → Pages → deploy from `main`, root) once the repo is public.
